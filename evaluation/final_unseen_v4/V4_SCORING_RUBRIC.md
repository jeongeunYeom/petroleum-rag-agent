# Frozen V4 semantic rubric

This rubric is fixed before any V4 model execution. Review the Agent and the closed-book Qwen answer against the same task gold. Do not consult development outcomes as judgment examples or change a task after observing a result.

## Task-level judgments

- **Goal Success (GS):** every requested gold goal is fulfilled correctly. All required numerical outputs need correct values and units. For an Agent KB-formula task, the actual literal source and a validated calculation are required; a coincidentally correct number is not enough. A false premise needs an explicit rejection, the corrected relation, and supporting KB evidence. An unanswerable task succeeds only with a truthful evidence-limited response and no invented formula or number. A resume task needs the targeted first-turn question and final completion on the same run after the fixed follow-up. The closed-book baseline is not required to cite unavailable KB, but its factual and numerical content must still be correct.
- **Task Completion (TC):** correct final interaction state. Answerable tasks should end with a completed answer; intended two-turn tasks should ask specifically then answer; unanswerable tasks should safely limit or refuse. TC alone does not imply semantically correct content.
- **Claim Coverage (CC):** count each delivered, correct required atomic claim and each correct required numerical output as one covered item. The denominator is all `gold.atomic_claims` plus all `gold.numeric_outputs` over all 60 tasks. Generic filler and a value attached to the wrong variable do not count. A missing claim receives zero coverage even when the remaining claims are correct.
- **Hallucination-Free (HF):** the complete visible answer contains no materially false engineering relation, invented formula/source, unsupported numerical assertion or wrong citation attribution. A cautious incomplete answer can be HF while failing GS. For the closed-book model, ordinary unsupported source attributions or factually incorrect engineering claims fail HF; absence of a KB citation alone does not.
- **Numerical Accuracy (NA):** among tasks with `gold.numeric_outputs`, pass only if every requested value is within its recorded tolerance, is attached to the right target, and has the correct physical unit/dimension. Do not count numbers appearing only in the prompt, source quote, citation ID, or an unvalidated intermediate as the answer. Units explicitly asked for must be visible. Dimensionless outputs need no unit label. This metric does not substitute for formula-provenance checks in GS.
- **Citation Support Rate (CSR):** for Agent KB-dependent answers, count each cited factual/formula/numeric claim as supported only when the cited actual source excerpt entails that claim. Denominator is all distinct cited atomic claims, not all valid citation IDs. An uncited required claim fails GS/CC as appropriate and is recorded as citation omission; it is not silently added to the CSR numerator. Invalid IDs, wrong pages, source text interpreted backwards, and irrelevant Figure notes are unsupported.

## Evidence and uncertainty

For every task preserve a verdict and brief source- or arithmetic-specific rationale for Agent and baseline. An automatic failure remains visible even if a semantic reviewer disagrees; explain the discrepancy. Mark `uncertain` when the actual source does not clearly decide the claim, the prompt is materially ambiguous, or the answer cannot be read reliably. Do not resolve uncertainty by assuming the gold is correct. If gold itself proves invalid after execution, retain the immutable task and flag `gold_issue`; do not edit or drop it. Report denominator changes, if any, explicitly.

The closed-book Qwen condition sees only the user-facing turns. It has no retrieval, source spans, calculation tool, or hidden gold. This comparison measures the Agent's KB/tool-enabled product against a no-tool baseline, not equal information access.
