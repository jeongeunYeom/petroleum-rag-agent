# Agentic Baseline v1 freeze policy

`agentic_heldout_v1` is an exploratory, 18-task, internal-KB-only paired comparison of a frozen product at `d13a6a107ab7b235dc6364eeba02d498a3bcb5ed`. ResearchAgent, GoalResearchAgent, retrieval, validators, CALC and deliverables must not be tuned from these results.

All 18 task prompts, author-written operational criteria, source-located ground truth, tolerances, figure mappings, rubric, model settings and scoring rules must be complete and checksummed before any held-out A/B/C output is generated. A synthetic fixture may smoke-test the harness; a held-out pilot is prohibited. The first full run freezes benchmark and rubric. Observing model output never authorizes changing them. A substantive correction requires a version bump, a new comparison and preservation of the original artifacts.

Run A for all tasks, then B for all tasks, then C for all tasks. A invokes `ResearchAgent.research` exactly once. B and C invoke the existing `GoalResearchAgent` with fixed author criteria; only C enables approved Python. Model `qwen3:8b`, temperature 0, seed 42, top-k 5, internal KB enabled, web disabled and the checked-out product's default retrieval mode `legacy` are common. Existing iteration and Python budgets are unchanged. If an internal generation component ignores seed, record that fact; do not adjust product code.

Every raw task result, including failures, belongs to the full run. A model parse failure handled by the product's existing bounded fallback is a model/system outcome, not an infrastructure omission. A true infrastructure failure (Ollama unavailable, corrupted file, runner crash) is logged separately. Never rerun only failed tasks. If a run must be repeated after an infrastructure fix, repeat all A/B/C tasks under a new run ID and retain the original. Do not quietly overwrite review or raw data.

Final-answer semantic review is blind to A/B/C and iteration metadata. Process review is separate. Deterministic checks supersede reviewer estimates for numbers, units, IDs, file existence, iteration counts, Python calls, stop reason, elapsed time and CALC validation. A reviewer discrepancy is flagged; adjudication is a separate v1.1 artifact and the original review remains intact. Internal goal coverage and status are telemetry, not external success.

The four-iteration external coverage curve uses last-observation-carried-forward after a run ends. Bootstrap resamples paired task IDs 10,000 times with seed 42 and reports percentile 95% confidence intervals. With only 18 tasks, all conclusions are exploratory. DOCX/PPTX checks are secondary reliability measures and never alter core agent ranking. OpenAI and Gemini APIs are prohibited. Existing frozen RAG and external-model benchmarks must not be edited or rerun.
